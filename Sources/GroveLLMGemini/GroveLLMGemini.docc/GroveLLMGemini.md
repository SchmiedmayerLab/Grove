## Overview

See the [GroveLLMOpenAI](../../GroveLLMOpenAI/GroveLLMOpenAI.docc/GroveLLMOpenAI.md) documentation for details.

- Important: GroveLLM's Gemini support is considered experimental, ans is implemented using the existing GroveLLMOpenAI infrastructure, via [Google's OpenAI compatibility layer](https://ai.google.dev/gemini-api/docs/openai).
    Not all features are necessarily supported; see Google's documentation for more details.
