Interact with Anthropic models in your app.

## Overview

See the [GroveLLMOpenAI](../../GroveLLMOpenAI/GroveLLMOpenAI.docc/GroveLLMOpenAI.md) documentation for details.

- Important: GroveLLM's Anthropic support is considered experimental, ans is implemented using the existing GroveLLMOpenAI infrastructure, via [Anthropic's OpenAI compatibility layer](https://platform.claude.com/docs/en/api/openai-sdk).
    Not all features are necessarily supported; see Anthropic's documentation for more details.
